## Hi there 👋

We're **Startline** — Australia's fitness event calendar. We connect athletes with the races, competitions, and communities that push them further.

Whether you're an athlete hunting your next race or an organiser filling your next start line, Startline is where it comes together.

## What we're building

- **[startline-web-app](https://github.com/StartlineAU/startline-web-app)** — the main platform: event discovery, registration, and race-day management for athletes and organisers.
- **[startline-mobile-app](https://github.com/StartlineAU/startline-mobile-app)** — native mobile companion, bringing the web experience to your phone.

## Get involved

- Found a bug or have a feature idea? Open an issue on the relevant repo.
- Want to contribute? Check the contributing guide in each repo and send a PR.
